# Troubleshooting
```bash
Problem	Fix
ModuleNotFoundError: No module named 'pynput'	Run pip install pynput
Linux: ImportError: No module named Xlib	sudo apt install python3-xlib
macOS: keys not detected	Grant Accessibility permission in System Settings and restart terminal
Permission denied on Linux	Run with sudo or add user to input group
[Errno 13] Permission denied for PID file	mkdir -p ~/.keystroke && chmod 777 ~/.keystroke
ADB: device unauthorized	Accept the RSA fingerprint prompt on the phone screen```
